The adapter invokes pipeline phases, reads authoritative post-billing actor resources, stops the same actor's attack, and routes supported delivery steps to `EntryDelivery`. The mandatory lifecycle callback must implement wait-user, guild initialization, conditional guild sends, PvP reset, conditional run mode and flush on the same actor and state. Invalid learned definitions require the existing original disconnect/log path before calling this adapter.

Limitations: no network-root wiring, complete world entry, full original-trace composition comparison, actual guild/world/transport providers, or playability claim. Actor state and guild lock synchronization remain the caller's responsibility. Zone admission remains a separate later operation. Next dependency is the connection owner that owns the loaded snapshot, serialized world wait, actual guild services and live client/manager transport; it must integrate this interface without adding another actor or replica owner.
